# Product Lessons

Short takes and reusable PM skills for building better products — especially in the AI era.

This is where I publish:
- **Takes** — essays on product judgment (stories → lessons → how I’ll apply them)
- **Skills** — Cursor/agent skills you can copy to pressure-test ideas, run demos, and build craft
- **Experiments** — thought-leadership tools I’m iterating on in public

Eventually this may become a [GitHub Pages](https://pages.github.com/) site. For now, everything is readable as markdown in the repo.

### Use a skill in Cursor

Copy `skills/product-council/` into your project’s `.cursor/skills/` (or install as a personal skill), then say:

`Run product council on [your idea or demo]`
